# KSE 30 Passive Portfolio Builder for Young Pakistani Professionals

A data-driven tool that helps young earners in Pakistan (PKR 200k–500k/month) construct and evaluate a passive KSE 30 investment portfolio using rupee-cost averaging (monthly SIP).

## Status
🚧 In development — building stage by stage.

## Overview
This project helps a young professional in Pakistan who:
- Recently graduated and started earning PKR 200,000–500,000/month
- Wants to invest PKR 50,000–150,000/month into the KSE 30
- Doesn't know how to start or how to think about risk

The tool models different monthly investment amounts, portfolio construction strategies, expected returns, dividend income, volatility, downside risk, rebalancing, transaction costs, and performance under different market scenarios.

## Setup
1. Clone this repo
2. Create a virtual environment: `python -m venv venv`
3. Activate it (Windows: `venv\Scripts\activate`, Mac: `source venv/bin/activate`)
4. Install dependencies: `pip install -r requirements.txt`
5. Open notebooks in `notebooks/` with Jupyter
